# 015 / 04 — Desk access from the Guildhall + clickable names

## Steps

1. In the GAME tab, walk to the Guildhall. A slim "► FACTION DESK" bar
   must appear with the scene; clicking it switches to COMMUNITY.
2. As a faction member, the Guildhall scene must show your role tags
   (ADMIN where applicable) and, for admins, a line counting requests
   waiting at the desk.
3. In COMMUNITY, click faction names in each board section (winners,
   wins ranking, most climbers, richest, highest) — every one must open
   that faction's page, with a working back link.

## Pass

- Guildhall → desk in one click; all board names clickable; back link
  returns to the board.

## Fail

- Desk unreachable from the guild context, or any board name inert.
